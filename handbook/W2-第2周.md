## D8 · 把文档变成「能被搜索」的形式

> **📍 在哪做**：虚拟机 `~/aiops` ｜ 新建 `corpus/`、`build_index.py`、`search_test.py`、`chroma/` ｜ 终端 1–2 个

### 今天的目标

把你的资料切块、转成向量、存进向量库，然后能用一句话搜出相关段落。

### 为什么做这一步

模型一次只能读几千个字，塞不下 20 篇文档。所以要先**检索**出最相关的几段，只把那几段给它。

**这就是 RAG 的全部思想：先查资料，再回答。**

**为什么用向量而不是关键词**

关键词搜索：搜「延迟高」只能匹配到含「延迟高」这三个字的段落。

向量搜索：把每段文字变成 1024 个数字（坐标），意思相近的文字坐标也相近。所以搜「接口变慢怎么办」也能匹配到「P95 延迟升高时的排查步骤」——字面完全不同，但意思一样。

### 用到的工具

| 工具 | 是什么 | 为什么是它 |
|---|---|---|
| **embedding 模型** | 把文字转成向量 | bge-m3 中文效果好，API 调用不用下载模型 |
| **Chroma** | 向量数据库 | 纯 Python，`pip install` 就能用，零部署 |
| **openai SDK** | 统一的 API 客户端 | 换个 base_url 就能换供应商 |

```python
# build_index.py —— 把 corpus 里的文档切块、转向量、存进 Chroma
import os
import re
import glob
import json
import sys

# RHEL 9 自带 sqlite 3.34.1 < chromadb 要求的 3.35.0，必须打这个补丁。
# 这四行必须在 import chromadb 之前，放在后面等于没放。
__import__('pysqlite3')
sys.modules['sqlite3'] = sys.modules.pop('pysqlite3')

from dotenv import load_dotenv
from openai import OpenAI
import chromadb

load_dotenv()

client = OpenAI(api_key=os.environ["API_KEY"], base_url=os.environ["BASE_URL"])
EMB_MODEL = os.environ.get("EMB_MODEL", "BAAI/bge-m3")

CORPUS_DIR = "corpus"
DB_DIR = "chroma"
MAX_CHARS = 800        # 每块最多 800 字
MIN_CHARS = 80         # 小于 80 字的块丢掉（多半是标题）


def split_markdown(text: str):
    """按二级标题切分。比按固定长度硬切好，因为语义是完整的。"""
    # 用 ## 作为分隔符切开
    parts = re.split(r"\n(?=## )", text)
    chunks = []
    for p in parts:
        p = p.strip()
        if len(p) < MIN_CHARS:
            continue
        # 太长的再按段落切
        if len(p) <= MAX_CHARS:
            chunks.append(p)
        else:
            buf = ""
            for para in p.split("\n\n"):
                if len(buf) + len(para) > MAX_CHARS and buf:
                    chunks.append(buf.strip())
                    buf = para
                else:
                    buf += "\n\n" + para
            if buf.strip():
                chunks.append(buf.strip())
    return chunks


def embed(texts):
    """调 API 把文字变成向量，一次最多 32 条，防止请求过大"""
    vectors = []
    for i in range(0, len(texts), 32):
        batch = texts[i:i + 32]
        resp = client.embeddings.create(model=EMB_MODEL, input=batch)
        vectors.extend([d.embedding for d in resp.data])
    return vectors


def main():
    # 每次重建都清空，避免重复
    if os.path.exists(DB_DIR):
        import shutil
        shutil.rmtree(DB_DIR)

    chroma = chromadb.PersistentClient(path=DB_DIR)
    col = chroma.create_collection(name="runbooks", metadata={"hnsw:space": "cosine"})

    ids, docs, metas = [], [], []
    for path in sorted(glob.glob(os.path.join(CORPUS_DIR, "*.md"))):
        name = os.path.basename(path)
        text = open(path, encoding="utf-8").read()
        chunks = split_markdown(text)
        for i, c in enumerate(chunks):
            ids.append(f"{name}#{i}")
            docs.append(c)
            metas.append({"source": name, "chunk": i})
        print(f"{name}: {len(chunks)} 块")

    print(f"总共 {len(docs)} 块，开始转向量...")
    vecs = embed(docs)

    col.add(ids=ids, documents=docs, embeddings=vecs, metadatas=metas)
    print(f"入库完成，共 {col.count()} 条")

    with open("corpus_stats.json", "w", encoding="utf-8") as f:
        json.dump({"chunks": len(docs), "sources": len(glob.glob(f'{CORPUS_DIR}/*.md'))}, f, ensure_ascii=False)


if __name__ == "__main__":
    main()
```

## D9 · 让模型「按格式」回答

> **📍 在哪做**：虚拟机 `~/aiops` ｜ 新建 `rag.py` ｜ 依赖 `.env` 里的 key ｜ 终端 1 个

### 今天的目标

把检索到的片段 + 用户问题拼成 prompt，让模型输出**严格的 JSON**。

### 为什么做这一步

模型天生爱聊天，你问它问题它会回一段散文。但程序要的是结构化数据：

```json
{"answer": "...", "citations": ["D06-cheatsheet.md"], "confidence": 0.8}
```

**格式不稳定，后面就全塌了**——第 3 周的分析器要靠 `answer` 字段做展示，靠 `citations` 做溯源。

### 用到的工具

| 工具 | 是什么 | 为什么是它 |
|---|---|---|
| **JSON mode** | API 参数 `response_format={"type":"json_object"}` | 强制模型只输出合法 JSON |
| **pydantic** | Python 数据校验库 | 校验字段类型，格式错误立刻发现 |

### 具体步骤

**1. 装 pydantic（一般已随 fastapi 装好）**

```bash

```

**2. 写问答模块**

```python
# rag.py —— 检索 + 生成，输出结构化结果
import os
import json
import sys
from typing import List

# 和 build_index.py 一样：这四行必须在 import chromadb 之前
__import__('pysqlite3')
sys.modules['sqlite3'] = sys.modules.pop('pysqlite3')

from dotenv import load_dotenv
from openai import OpenAI
import chromadb
from pydantic import BaseModel, ValidationError

load_dotenv()

client = OpenAI(api_key=os.environ["API_KEY"], base_url=os.environ["BASE_URL"])
CHAT_MODEL = os.environ.get("CHAT_MODEL", "Qwen/Qwen2.5-7B-Instruct")
EMB_MODEL = os.environ.get("EMB_MODEL", "BAAI/bge-m3")   # 默认值必须和建库时同一个
col = chromadb.PersistentClient(path="chroma").get_collection("runbooks")

SYSTEM = """你是一个运维知识库助手。必须遵守：
1. 只能依据【资料】回答，资料里没有就说"资料中没有相关信息"，不要编造
2. 输出必须是 JSON，格式：
   {"answer": "回答内容", "citations": ["文件名1", "文件名2"], "confidence": 0到1的小数}
3. citations 只填资料里出现过的文件名
4. confidence 表示你对答案的把握，资料没覆盖就填 0.2 以下"""


class RagAnswer(BaseModel):
    answer: str
    citations: List[str]
    confidence: float


def retrieve(question: str, k: int = 5):
    vec = client.embeddings.create(model=EMB_MODEL, input=[question]).data[0].embedding
    r = col.query(query_embeddings=[vec], n_results=k)
    return list(zip(r["documents"][0], r["metadatas"][0], r["distances"][0]))


def build_context(hits):
    parts = []
    for doc, meta, _ in hits:
        parts.append(f"【{meta['source']}】\n{doc}")
    return "\n\n---\n\n".join(parts)


def answer(question: str, k: int = 5) -> dict:
    hits = retrieve(question, k)
    context = build_context(hits)

    resp = client.chat.completions.create(
        model=CHAT_MODEL,
        messages=[
            {"role": "system", "content": SYSTEM},
            {"role": "user", "content": f"【资料】\n{context}\n\n【问题】\n{question}"},
        ],
        response_format={"type": "json_object"},   # 强制 JSON
        temperature=0.1,                            # 越低越稳定
    )
    raw = resp.choices[0].message.content

    try:
        data = json.loads(raw)
        parsed = RagAnswer(**data)
        return {"ok": True, **parsed.model_dump(), "raw": raw}
    except (json.JSONDecodeError, ValidationError) as e:
        return {"ok": False, "error": str(e), "raw": raw}


if __name__ == "__main__":
    import sys
    q = " ".join(sys.argv[1:]) or "服务响应突然变慢应该先看什么"
    print(json.dumps(answer(q), ensure_ascii=False, indent=2))
```

### 卡住了看这里

| 现象 | 原因 | 解决 |
|---|---|---|
| 报 `response_format` 不支持 | 供应商不支持 JSON mode | 去掉这行，改成在 prompt 里强调，再手动 `json.loads` |
| 模型输出带 ```json 包裹 | 模型习惯 | 用正则剥掉：`re.sub(r"^```json|```$", "", raw.strip())` |
| `ValidationError` | 字段缺失或类型不对 | 打印 `raw` 看模型实际给了什么，再调 prompt |
| 回答很空泛 | 检索到的片段不相关 | 回 D8 检查语料和切分 |
| `RuntimeError: ... unsupported version of sqlite3` | 忘了打 pysqlite3 补丁 | 见 D8 第 3 步代码开头那四行，**必须放在 `import chromadb` 之前** |
| 检索结果突然全变噪声 | 建库和查询用了不同的 embedding 模型 | 两边都写死 `BAAI/bge-m3`，然后重建索引 |

## D10 · 造一把尺子（评测集）

### 今天的目标

## D11 · 跑第一次评测

> **📍 在哪做**：虚拟机 `~/aiops` ｜ 新建 `run_eval.py` ｜ 产出 `eval_result.json` ｜ 终端 1 个

### 今天的目标

写一个脚本，自动算出 recall@5 和答案正确率，跑出第一版数字。

### 为什么做这一步

你现在需要知道「基线在哪」。第一版数字通常很难看（recall 0.5 左右），这很正常——**没有基线，你就不知道调优有没有用**。

### 两个指标是什么

| 指标 | 怎么算 | 说明 |
|---|---|---|
| **recall@5** | 检索的前 5 条里，有没有命中期望文件 | 衡量「找得到吗」 |
| **答案正确率** | 人工给答案打 0/1/2 分 | 衡量「答得对吗」 |
| **拒答正确率** | 5 条陷阱题里，正确说「不知道」的比例 | 衡量「会不会瞎编」 |

为什么是 recall@5 不是 recall@1？因为 RAG 会把 5 条都塞给模型，只要有一条对，模型就有机会答对。

### 具体步骤

```bash
vim run_eval.py
```

```python
# run_eval.py —— 跑评测，输出 recall + 待人工打分的答案
import json
import os
import sys

from rag import retrieve, answer, col

EVAL_FILE = "eval_set.json"
OUT_FILE = "eval_result.json"


def main():
    data = json.load(open(EVAL_FILE, encoding="utf-8"))
    items = data["items"]

    results = []
    hit = 0
    total_answerable = 0
    reject_ok = 0
    total_unanswerable = 0

    for it in items:
        q = it["question"]
        hits = retrieve(q, k=5)
        sources = [m["source"] for _, m, _ in hits]

        rec = {"id": it["id"], "question": q, "answerable": it["answerable"],
               "expected": it.get("expected_source"), "retrieved": sources}

        if it["answerable"]:
            total_answerable += 1
            if it["expected"] in sources:
                hit += 1
                rec["recall_hit"] = True
            else:
                rec["recall_hit"] = False
        else:
            total_unanswerable += 1

        # 生成答案（后面人工打分）
        try:
            r = answer(q, k=5)
            rec["answer"] = r.get("answer", "")
            rec["citations"] = r.get("citations", [])
            rec["confidence"] = r.get("confidence", 0)
            rec["ok"] = r.get("ok", False)
        except Exception as e:
            rec["answer"] = f"[ERROR] {e}"
            rec["ok"] = False

        # 无答案题自动判断是否拒答
        if not it["answerable"]:
            said_unknown = ("没有" in rec["answer"]) or ("未提及" in rec["answer"]) or ("不知道" in rec["answer"])
            rec["reject_ok"] = said_unknown
            if said_unknown:
                reject_ok += 1

        results.append(rec)
        mark = "✓" if rec.get("recall_hit") else ("·" if not it["answerable"] else "✗")
        print(f"[{mark}] {it['id']:>2} {q[:30]}")

    recall = hit / total_answerable if total_answerable else 0
    reject_rate = reject_ok / total_unanswerable if total_unanswerable else 0

    summary = {
        "recall@5": round(recall, 3),
        "reject_rate": round(reject_rate, 3),
        "total": len(items),
        "answerable": total_answerable,
        "unanswerable": total_unanswerable,
    }
    print("\n=== 结果 ===")
    print(json.dumps(summary, ensure_ascii=False, indent=2))

    json.dump({"summary": summary, "items": results}, open(OUT_FILE, "w", encoding="utf-8"),
              ensure_ascii=False, indent=2)
    print(f"\n明细已写入 {OUT_FILE}，请人工给 answer 打 0/1/2 分")


if __name__ == "__main__":
    main()
```

### 为什么做这一步

**调优能力比「能跑起来」值钱得多**。面试时问「召回不准怎么调」，你要能说出 3 种手段和各自效果。

### 三个最有效的手段（按性价比排序）

**手段 1：改切分粒度（最先试）**

| 切太大（>1500 字） | 切太小（<100 字） |
|---|---|
| 一块里混了好几个主题，向量被稀释，检索不准 | 语义不完整，检索到了也没用 |

把 `MAX_CHARS` 从 800 改成 500 或 1200，各跑一次评测，看数字。

**手段 2：混合检索（提升最明显）**

纯向量搜索对**专有名词**很差。比如搜「ens33」或「recall@5」，向量模型不认识这些词，但关键词能精确匹配。

混合检索 = 向量结果 + 关键词结果，合并去重。

```bash
pip install rank-bm25 jieba
```

```python
# hybrid.py
import jieba
from rank_bm25 import BM25Okapi

def build_bm25(docs):
    tokenized = [list(jieba.cut(d)) for d in docs]
    return BM25Okapi(tokenized)

def bm25_search(bm25, docs, metas, query, k=5):
    tokens = list(jieba.cut(query))
    scores = bm25.get_scores(tokens)
    idx = sorted(range(len(scores)), key=lambda i: -scores[i])[:k]
    return [(docs[i], metas[i]) for i in idx]
```

合并策略：两路各取 5 条，按 id 去重，总共取前 8 条给模型。

**手段 3：加「拒答」提示（提升拒答率）**

在 SYSTEM prompt 里加一句：

```
如果你在【资料】里找不到直接依据，必须回答"资料中没有相关信息"，禁止根据常识推测。
```
