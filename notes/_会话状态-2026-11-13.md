## 四、踩过的坑（面试可直接讲）

第 1 周：

1. **`tc netem` 延迟不生效**：本机 curl 本机 IP 走回环 `lo`，不经过 `ens33`；且 netem 默认只管出站。→ 测本机服务把规则加到 `lo`，或从另一台机器发起；结束用 `tc qdisc del` 清理。
2. **告警突然不推**：两个原因叠加——receiver 是前台进程，重启后没起来（`ss -tlnp | grep 8001` 无输出）；Prometheus 重启后 `for` 计时归零需要重新累计。`-k` 参数与此无关（明文 HTTP 不走证书校验）。
3. **Compose 挂载报错**：YAML 只能用空格缩进；挂载配置用 `:ro`；宿主机必须先有实体文件，否则 Docker 建成同名目录。
4. **Grafana 加面板报错**（第 24 轮）：版本问题，改数据源/默认仪表盘无效，最终走版本兼容路径解决。
5. **Prometheus target down**（第 26 轮）：忘了起 uvicorn；另确认该进程不在 Docker 内。
6. **8000 端口反复被占**：杀一个又冒一个，因 systemd 托管（`aiops-app.service`/`aiops-traffic.service`）会自动拉起 —— 要从 systemd 层面停，别只 kill。
7. **日志里 client 是 127.0.0.1**：容器内访问宿主服务走 `host.docker.internal`，源地址自然是本地回环。

第 2 周新增：

8. **RHEL 9 自带 sqlite 3.34.1 < chromadb 要求的 3.35.0**：`import chromadb` 直接 RuntimeError。解法是 `pip install pysqlite3-binary`，并在 **`import chromadb` 之前**替换 `sys.modules['sqlite3']`（D8）。
9. **`ModuleNotFoundError: No module named 'pysqlite3'` 多半不是代码问题**：是 venv 没激活，此时 `python` = `/usr/bin/python`，看不见 `.venv` 里的包。看到 `No module named` 先 `which python`（D9）。
10. **未激活时 `pip install` 会把包漏进 `~/.local`**：venv 里依然没有，还会串进系统 python 造成版本诡异（D9）。
11. **`sudo cd` 无效**：`cd` 是 shell 内建命令，sudo 起子进程 cd 完就退；跨目录搬文件用 `sudo cp`（D8）。
12. **LLM 调用不设 `timeout` 会「假死」**：`OpenAI(...)` 默认超时 600 秒，某条请求网络一抖就阻塞几分钟，表现为「跑到第 6 条就卡住」。必须显式 `timeout=30.0, max_retries=2`；embedding 调用同理（D12）。
13. **「写了新模块」≠「用上了新模块」**：`hybrid.py` 写好后 `run_eval.py` 仍是 `from rag import retrieve`，跑出的数字一字未变。查三处：`grep` 调用点、文件 md5 有没有变、**输出数字有没有变**（最硬）（D12）。
14. **索引与源码会不同步**：改了 `MAX_CHARS` 却没重跑 `build_index.py`，`chroma/` 里还是旧块数。判断有没有重建看 `corpus_stats.json` 的 mtime，不要看 `chroma/` 目录（查询也会写元数据）（D12）。

环境类（不属于项目本身，但一样会把你卡住）：

12. **宿主机连不上虚拟机（2026-11-17）**：MobaXterm/ssh 超时，但虚拟机是开着的。真因是宿主 **VMware VMnet8 丢了静态 IP**（掉到 `169.254.x`），路由表里没有任何 `192.168.223.0/24` 路由。修复：`netsh interface ip set address name="VMware Network Adapter VMnet8" static 192.168.223.1 255.255.255.0`（VMnet1 同理恢复 `192.168.0.1`）。
13. **别用 ping 判断虚拟机通不通**：RHEL 防火墙拦 ICMP，实测 `ping` 100% 丢包的同时 `ssh` 正常。判据用 22 端口或直接 `ssh`。
14. **虚拟机已改静态 IP**：原来走 DHCP 且租期只有 1800 秒，重启就可能换地址、又「连不上」一次。现在 `ens33` = `192.168.223.129/24`，网关/DNS `192.168.223.2`；改前配置备份在虚拟机 `/root/ens33-before-static.txt`。
