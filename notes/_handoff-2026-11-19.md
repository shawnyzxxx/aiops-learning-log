## 六、D11 的详细计划（已完成，留作参考）

**目标**：写 `run_eval.py`，自动算出 recall@5 + 答案正确率（待人工打分）+ 拒答率，跑出第一版数字。

**在哪做**：虚拟机 `~/aiops`，新建 `run_eval.py`，产出 `eval_result.json`

**验收线**：脚本跑通，输出 recall@5 数字、5 条陷阱题各有一条 `reject_ok` 判断。基线难看是正常的（约 0.5）。

**核心逻辑**（手册已给，直接抄）：

```python
# run_eval.py —— 读 eval_set.json，逐条 retrieve 算 recall@5，逐条 answer 落盘
import json
from rag import retrieve, answer

EVAL_FILE = "eval_set.json"
OUT_FILE = "eval_result.json"

def main():
    data = json.load(open(EVAL_FILE, encoding="utf-8"))
    items = data["items"]
    results, hit, total_answerable = [], 0, 0
    reject_ok, total_unanswerable = 0, 0

    for it in items:
        q = it["question"]
        hits = retrieve(q, k=5)
        sources = [m["source"] for _, m, _ in hits]
        rec = {"id": it["id"], "question": q, "answerable": it["answerable"],
               "expected": it.get("expected_source"), "retrieved": sources}
        if it["answerable"]:
            total_answerable += 1
            if it["expected"] in sources:
                hit += 1; rec["recall_hit"] = True
            else:
                rec["recall_hit"] = False
        else:
            total_unanswerable += 1
        try:
            r = answer(q, k=5)
            rec.update({"answer": r.get("answer",""), "citations": r.get("citations",[]),
                        "confidence": r.get("confidence",0), "ok": r.get("ok",False)})
        except Exception as e:
            rec.update({"answer": f"[ERROR] {e}", "ok": False})
        if not it["answerable"]:
            said_unknown = ("没有" in rec["answer"]) or ("不知道" in rec["answer"]) or ("未提及" in rec["answer"])
            rec["reject_ok"] = said_unknown
            if said_unknown: reject_ok += 1
        results.append(rec)
        mark = "✓" if rec.get("recall_hit") else ("·" if not it["answerable"] else "✗")
        print(f"[{mark}] {it['id']:>2} {q[:30]}")

    recall = hit / total_answerable if total_answerable else 0
    reject_rate = reject_ok / total_unanswerable if total_unanswerable else 0
    summary = {"recall@5": round(recall,3), "reject_rate": round(reject_rate,3),
               "total": len(items), "answerable": total_answerable, "unanswerable": total_unanswerable}
    print("\n=== 结果 ===\n" + json.dumps(summary, ensure_ascii=False, indent=2))
    json.dump({"summary": summary, "items": results}, open(OUT_FILE,"w",encoding="utf-8"), ensure_ascii=False, indent=2)
    print(f"\n明细已写入 {OUT_FILE}，请人工给 answer 打 0/1/2 分")

if __name__ == "__main__": main()
```

**⚠️ 必须先 `source .venv/bin/activate`**（`run_eval.py` import `rag` → import `chromadb`）

**跑法**：
```bash
cd ~/aiops
source .venv/bin/activate
python run_eval.py
```

## 十、RAG 技术架构（快速参考）

```
corpus/*.md (16 篇)
  ↓ split by ## (MAX_CHARS=800, MIN_CHARS=80)
chunks (130 个)
  ↓ bge-m3 embedding (via SiliconFlow API)
vectors → Chroma (persistent, path="chroma/")

用户问题 → bge-m3 embedding → col.query(n_results=5)
  → build_context (拼接 5 段) → ChatModel (Qwen/Qwen2.5-7B-Instruct, temperature=0.1, json_object)
  → pydantic RagAnswer 校验 → {answer, citations, confidence}
```

- embedding 模型：`BAAI/bge-m3`
- chat 模型：`Qwen/Qwen2.5-7B-Instruct`
- API 供应商：硅基流动（`https://api.siliconflow.cn/v1`）
- RHEL sqlite 问题：`pysqlite3-binary` 补丁，在 `import chromadb` 之前替换 `sys.modules['sqlite3']`
